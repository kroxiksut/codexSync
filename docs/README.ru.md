разработчика. В каждом языке одни и те же восемь страниц; документы для
разработчика существуют только на английском.

## Скриншоты

В `screenshots/<язык>/` лежат скриншоты окна, которые встраивают страницы выше.
Их создаёт `scripts/docs_screenshots.py` на выдуманных демонстрационных данных,
никогда не из настоящей конфигурации.

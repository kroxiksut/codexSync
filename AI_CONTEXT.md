# AI CONTEXT

## PURPOSE
`CODEXSYNC` IS A LOCAL TOOL (COMMAND LINE FIRST, OPTIONAL WINDOW) THAT HANDS CODEX WORK BETWEEN A PERSON'S OWN MACHINES THROUGH A FOLDER THEY ALREADY SYNC: SETTINGS, CHATS, CHAT NAMES AND THE PROJECT LIST, WITH VERIFIED BACKUPS AND RECOVERY. CURRENT LINE: 0.2 (ALPHA `0.2.0a1`).

## GOAL
ALLOW DEVELOPERS TO CONTINUE WORK ON ANOTHER MACHINE WITH EVERY CHAT, ITS NAME AND ITS PROJECT WHERE CODEX LOOKS FOR THEM, WITHOUT LOSING CODEX LOCAL CONTEXT.

## CORE ASSUMPTIONS
- WRITES HAPPEN ONLY WHEN CODEX IS FULLY CLOSED. READS, PLANS AND GUARDIAN SNAPSHOTS RUN WHILE IT IS OPEN.
- ONLY ONE ACTIVE MACHINE IS USED AT A TIME.
- THE USER IS RESPONSIBLE FOR CLOUD SYNC READINESS AND AVAILABLE STORAGE CAPACITY.
- THE PROJECT DOES NOT USE CODEX APIS, DOES NOT INTERCEPT NETWORK TRAFFIC AND NEVER TERMINATES CODEX BY FORCE. IF THE USER TURNS ON `[sync] close_codex`, A SYNC ASKS THE DESKTOP APP TO QUIT AND REFUSES IF IT DOES NOT (`D-029`).
- CODEX'S OWN FILES ARE EDITED ONLY THROUGH THE MUTATION ENVELOPE, AND ITS SQLITE IN EXACTLY TWO NARROW PLACES: THE `backfill_state` ROW -- `pending` WHEN A PERSON ASKS FOR A CHAT-LIST REBUILD (`D-024`), BACK TO `complete` WHEN A REBUILD IS STUCK (`codex repair`, `D-032`); A SYNC NEVER ASKS -- AND `threads.name` WHERE IT IS UNSET (`D-025`). NEVER A `threads` ROW, NEVER PROJECT RECORDS, NEVER `session_index.jsonl`.

## TARGET PLATFORMS AND VERSIONS
- PYTHON: `3.11+` (MINIMUM SUPPORTED VERSION, MATCHES `pyproject.toml`).
- WINDOWS: `WINDOWS 10 (1809)+`, X64 AND ARM64 (CODEX ITSELF SHIPS ONLY THESE; NO 32-BIT BUILD). THE TESTED PLATFORM.
- MACOS (APPLE SILICON): CODE AND CI. WRITES ARE REFUSED UNTIL `PROVEN_DETECTORS` HOLDS AN OBSERVED ENTRY. THE WINDOW NEEDS MACOS 13+ (PYSIDE6). INTEL MAC IS NOT A TARGET.
- LINUX: EXPERIMENTAL (D-031). CODEX DESKTOP FOR LINUX IS IN PREVIEW SINCE 2026-08 (UBUNTU 24.04/26.04, DEBIAN 13, FEDORA 43/44, ARCH; X64/ARM64). CODE AND CI RUN; WRITES ARE REFUSED UNTIL `PROVEN_DETECTORS` HOLDS AN OBSERVED ENTRY (CS-396).

## CI COVERAGE
- CI RUNNERS: `WINDOWS-LATEST`, `MACOS-LATEST`, PYTHON 3.11/3.12/3.13/3.14, PLUS A GUI JOB.
- `UBUNTU-LATEST` RUNS THE SAME JOBS AS EXPERIMENTAL: A RED LINUX JOB DOES NOT FAIL THE RUN (D-031).
- RELEASES: `release.yml` (MANUAL), PYPI THROUGH TRUSTED PUBLISHING, WINDOWS BUILDS ATTACHED.

## RUN MODES
- DIRECT RUN: `codexsync` (CLI), `codexsync-gui` (WINDOW), OR THE PACKAGED `.EXE` FILES.
- CONFIG BOOTSTRAP: `INIT-CONFIG` GENERATES `config.toml` FROM THE TEMPLATE BUNDLED INSIDE THE PACKAGE; `CONFIG CHECK|UPGRADE` MIGRATES A 0.1 CONFIG.
- DIAGNOSTIC RUN: `DOCTOR`/`PREFLIGHT`, SIDE-EFFECT FREE.
- SYNC: `SYNC` IS A FULL SYNC BY DEFAULT (`D-028`); `--scope settings` IS FILES ONLY.
- SCHEDULED RUN (USER-LEVEL OS TASKS: WINDOWS TASK SCHEDULER, MACOS `LAUNCHD`):
  - HANDOFF WATCHER: SYNCS WHEN CODEX CLOSES AND AT SIGN-IN (`D-018`).
  - ONE SYNC AFTER SIGN-IN (`D-016`).
  - COPIES OF `.codex` (`D-017`).
  - A PERIODIC SAFETY-NET JOB: `guardian_snapshot|preflight|sync_dry_run`, EVERY 30 MIN BY DEFAULT, NEVER UNDER 5.

## 0.2 FEATURES
1. GUARDIAN: IMMUTABLE VERIFIED SNAPSHOTS OF THE GLOBAL STATE WHILE CODEX RUNS, WRITTEN ONLY OUTSIDE `.codex`; `GUARDIAN ACCEPT` AND `GUARDIAN RESTORE`.
2. SINGLE MUTATION AUTHORITY (`safety_gate`) AND A SINGLE MUTATION ENVELOPE: LOCK, JOURNAL, VERIFIED BACKUP, FINAL CHECK, ATOMIC REPLACE.
3. `RECOVER LIST|INSPECT|RESUME|ROLLBACK` FOR AN INTERRUPTED MUTATION; `HISTORY` OF EVERY SYNC.
4. CHATS BETWEEN MACHINES: SEMANTIC BRANCH CLASSIFICATION; IN PLACE (`D-019`), NEW CHATS AT THEIR SOURCE PATH (`D-020`), ARCHIVE MOVES (`D-023`), PAGED CHATS AND CONFLICTS BY RULE (`D-027`). A DIVERGENCE IS NEVER MERGED.
5. PROJECTS: LIST MERGE BETWEEN MACHINES (`D-022`), FOLDER COMPARISON (`D-026`), `REPAIR-PROJECTS`, `CHATS MOVE`, PROJECT MOVE.
6. MACHINE HANDOFF RECORD AND NOTIFICATIONS (`D-018`).
7. OPTIONAL GUI EXTRA `codexsync[gui]` (AND `codexsync-gui.exe`): A SECOND SHELL OVER THE SAME CORE; EVERY WINDOW ACTION ALSO EXISTS IN THE CLI; CORE AND CLI KEEP ZERO RUNTIME DEPENDENCIES.

## STILL GATED (FILLED ONLY FROM AN EXPERIMENT IN `docs/dev/experiments/`)
- `PROVEN_LAYOUTS`: A GENERAL PLACEMENT RULE FOR NEW SESSIONS.
- `PROVEN_CONTRACTS`: REWRITING `session_index.jsonl`.
- `PROVEN_DETECTORS`: MACOS/LINUX PROCESS DETECTION.
- `PROVEN_PROJECT_REGISTRY`: PROJECT DELETE/MERGE, SQLITE PROJECT ROOTS.
- `PROVEN_CLOSERS`: ASKING CODEX TO QUIT ON MACOS.

## SAFETY CRITERIA
- NEVER WRITE TO STATE WHILE CODEX IS RUNNING; `UNKNOWN` COUNTS AS RUNNING.
- ALWAYS CREATE A VERIFIED BACKUP BEFORE OVERWRITE OR DELETE.
- ON UNCERTAINTY, FAIL-SAFE (ABORT WITHOUT WRITES).

## RECORDED DECISIONS
- CONFLICT POLICY (`D-027`): IF BOTH SIDES CHANGED, `[conflict] policy` DECIDES FILES AND CHATS ALIKE: `prefer_newer_mtime` (DEFAULT; A CHAT BY ITS LAST RECORD), `prefer_local`, `prefer_cloud`, OR `manual_abort`. THE COPY NOT KEPT IS SAVED (BACKUP, OR A CHAT WHOLE IN THE CONFLICT BUNDLE). A RECORDED MANUAL CHOICE OUTRANKS THE RULE; A TIE OR AN UNKNOWN TIME ASKS (EXIT `2`).
- LOGGING:
  - LEVELS: `DEBUG|INFO|WARNING|ERROR`.
  - FORMATS: `TEXT|JSON|LOGFMT` (CONFIGURABLE).
  - ROTATION: RETENTION-BASED, DEFAULT `7` DAYS.
- FILE-TIME NORMALIZATION: NO CLOCK COMPENSATION; RELY ON OS/FILESYSTEM TIMESTAMPS. THE MANIFEST KEEPS ONE BASELINE PER MACHINE.
- SYNC DIRECTION (`D-012`): `BIDIRECTIONAL|TO_CLOUD|TO_LOCAL`, ALSO `--direction` FOR ONE RUN. A SKIPPED SIDE IS NEVER RECORDED AS SYNCHRONISED; THE PREVIOUS MANIFEST ENTRY IS CARRIED OVER UNCHANGED. A ONE-WAY DIRECTION DECIDES CHAT CONFLICTS TOO.
- DELETE POLICY (`D-013`): `NEVER|PROPAGATE`. A DELETION TRAVELS ONLY WHERE THE
  PREVIOUS MANIFEST PROVES BOTH SIDES HELD THE FILE AND THE SURVIVING SIDE HAS
  NOT CHANGED; A VERIFIED BACKUP IS WRITTEN FIRST, INSIDE THE SAME ENVELOPE.
  SEMANTIC-OWNED PATHS ARE NEVER DELETED BY `SYNC`.
- SESSION WORKING SET: NARROWS ONLY WHAT IS WRITTEN INTO `.codex`. THE CLOUD
  MIRROR IS ALWAYS COMPLETE, AND THE SET IS PART OF THE PLAN ID.
- ON-DISK FORMATS (`D-030`): EVERYTHING 0.2.0a1 WRITES STAYS READABLE BY LATER VERSIONS (`tests/fixtures/ws-a1/`).
- PREFLIGHT/DOCTOR CHECKS:
  - CONFIG + RUNTIME PATH READINESS, CONFIG COMPATIBILITY WITH 0.1.
  - READ ACCESS AND DIRECTORY SHAPE FOR LOCAL/CLOUD/BACKUP/TEMP ROOTS.
  - CODEX PROCESS SAFETY PRECONDITION.
  - MANIFEST DATA-VERSION COMPATIBILITY.
  - SESSION CATALOG AUDIT (INVALID/AMBIGUOUS SESSIONS, FORMAT, CHATS CODEX HAS NOT LISTED).
  - READ-ONLY SQLITE AUDIT (IT NEVER CREATES `-wal`/`-shm`).
  - ORPHAN TEMP FILE DETECTION.
  - WHAT A SYNC IS ALLOWED TO DO (DIRECTION AND DELETE POLICY).
  - WHERE PROJECTS ARE STORED: CODEXSYNC EDITS PROJECT ROOTS IN JSON ONLY, WHILE THE
    RUNTIME ALSO KEEPS PROJECTS IN `state_*.sqlite`.
  - DOCTOR/PREFLIGHT IS SIDE-EFFECT FREE: IT NEVER WRITES A PROBE FILE.
- CLI EXIT CODES (FOR CI/AUTOMATION):
  - `0` SUCCESS (INCLUDING NO-OP).
  - `1` RUNTIME ERROR.
  - `2` A CONFLICT OR CHOICE THE CONFIGURED RULE LEAVES OPEN; NOTHING WRITTEN.
  - `3` CODEX IS RUNNING (AND WAS NOT CLOSED ON REQUEST), WRITE BLOCKED.
  - `4` CONFIG OR ARGUMENT ERROR.
  - `5` SAFE ABORT (`FAIL-SAFE`) DUE TO UNCERTAIN STATE, A BUSY LOCK OR A PENDING RECOVERY.
